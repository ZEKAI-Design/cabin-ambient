# Cabin Ambient

An iDrive 7 ambient lighting app for the BMW X5 G05. Version 0.8.0 controls static colours and continuously sampled Breathe, Rainbow, and Colour loop effects through the existing IterioDev Comfort service. The 2019 G05 owner has confirmed the car controls work.

Dynamic effects have no 30-second limit and continue while Cabin Ambient is running, including when its page is hidden. Static colours remain applied after the command completes. The app ignores Comfort's false fault flags for the working footwell modules.

## Install with MGU Store

1. Open **MGU Store → Settings → Add source**.
2. Enter `ZEKAI-Design/cabin-ambient` and choose **Releases**.
3. Return to **Store**, open **Cabin Ambient**, and select **Install**. If it is already installed, use **Installed → Update**.
