# Cabin Ambient

An iDrive 7 ambient lighting app for the BMW X5 G05. The 0.7.1 test release sends static colours and sampled dynamic effects to the car through its existing IterioDev Comfort service while parked.

## Install with MGU Store

1. Connect the head unit to the internet.
2. Open **MGU Store → Settings → Add source**.
3. Enter `ZEKAI-Design/cabin-ambient` and choose **Releases**.
4. Return to **Store**, open **Cabin Ambient (Live Car Test)** and select **Install**. If it is already installed, use **Installed → Update**.
