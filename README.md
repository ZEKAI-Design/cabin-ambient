# Cabin Ambient

An iDrive 7 interface preview for the BMW X5 G05. Preview ambient lighting effects and set colours for the whole cabin, a zone, or a strip. Physical ambient light control has not been integrated.

## Install with MGU Store

1. Connect the head unit to the internet.
2. Open **MGU Store → Settings → Add source**.
3. Enter `ZEKAI-Design/cabin-ambient` and choose **Releases**.
4. Return to **Store**, open **Cabin Ambient (Preview)** and select **Install**.
